Support

Last updated 6 September 2026

Spec Layer is maintained by an independent developer. Email oleksandr.kurchev@gmail.com and expect a reply within a few business days.

Before you write

  • License key not accepted. The plugin's License screen tells you whether the key is invalid, expired, disabled, or already active on the maximum number of devices. For the device limit, free a device in Manage subscription and try again. If the screen says verification is temporarily unavailable, your plan has not changed; try again in a minute.
  • AI writing did not run. The frame is still created; AI sections carry a placeholder. The License screen shows your remaining free uses. Failed calls do not count against them.
  • Publishing failed. The Publish screen names the reason: a Pro license is needed, the library is over the 5 MB limit, the license already publishes 10 libraries, or a source component could not be read. Nothing partial is published.
  • The pull key was rotated. Developers get a message from the CLI naming the fix: run the new setup command copied from the plugin's Publish screen.
  • Refunds. Within 30 days, for any reason. See the Refund Policy.

What to include

  • Which screen you were on and what you clicked.
  • The exact message the plugin showed, if any.
  • Your Lemon Squeezy order number for billing questions, never your license key.

Please do not send private design files. If a problem depends on a specific component, a description of its structure is enough to start with.
