Three terms to know

Canvas docs
Readable Figma documentation connected to its source. The Library helps you check and update it.
Context
Structured component specifications and design tokens. Component copies use YAML; foundation copies use the Design Tokens Community Group (DTCG) JSON format.
Published library
A snapshot uploaded from Figma. The CLI downloads this snapshot, so unpublished design changes do not appear in a pull.

Versions covered here

This reference covers CLI {{cliVersion}} and canonical Context schema {{schemaVersion}}. The v5 schema URL identifies the major contract; the artifact contains its exact schema version.
