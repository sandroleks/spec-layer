Date: 2026-09-09. Branch `feat-css-token-directory`, bundle built from
commit `862eab6`. Design:
`docs/superpowers/specs/2026-09-09-css-token-directory-design.md`. Plan:
`docs/superpowers/plans/2026-09-09-visible-outputs.md`, Task 10.

The unit tests prove the projection against the synthetic Foundation. This
run proves the directory rules against a real published library, in a tree
that a published `spec-layer@0.6.0` had written earlier the same day. The
tree is a private scratch project; nothing from it is committed, and the
library id is masked below.

A 0.6.0 pull: `speclayer.json` with `"path": "spec-layer/tokens.css"`,
`spec-layer/tokens.css` (515 lines), `.speclayer/` holding the record and
`components/buttonprimary.yaml`, and an `AGENTS.md` from `skill --install`.

## 3. `index.css` in a browser

The `tokens/` directory and a two-section page (one section carrying
`data-theme="dark"`) were served over `http://localhost:4633`. Every import
answered `200`, and `document.styleSheets` reported seven loaded import
rules with one rule each. Console: no messages.

| Element | Property | Computed |
|---|---|---|
| light, surface primary default | `--colors-blue-500` | `rgb(46, 114, 209)` |
| light, surface neutral canvas | `--colors-gray-25` | `rgb(247, 248, 250)` |
| dark, surface primary default | `--colors-blue-500` | `rgb(46, 114, 209)` |
| dark, surface neutral canvas | `--colors-gray-1000` | `rgb(0, 0, 0)` |

The dark file overrides the canvas and leaves primary alone, which is what
the library declares.

## 4. No-op, and a deleted file comes back

The first attempt at this step found a defect. After deleting
`tokens/semantic-colors.dark.css`, the bundle built from `d418fc7` answered
`Already up to date` and left the file missing. Cause: the freshness check
and the guide took the list of written files from the record map, whose
`file` names only the first file declaring each token, which for a two-mode
collection is always the default mode's file. The dark file was never in the
list. Fixed in `862eab6` (`readIndexImports`: `index.css` is the list), spec
section 7 amended in `459b655`, and the step re-run:

```text
$ node .../cli.js pull                 (dark file missing)
Pulled Design System Variables: foundation + 1 component (published 2026-09-09T12:52:39.886Z).
Wrote 14 files under .speclayer/.
Wrote component-specs/ (1 file).
Wrote tokens/ (8 files, web/css, kebab names).
exit=0                                 (8 files, dark file back)

$ node .../cli.js pull
Already up to date (published 2026-09-09T12:52:39.886Z).
exit=0

$ rm tokens/semantic-colors.dark.css && node .../cli.js pull
Pulled Design System Variables: foundation + 1 component (published 2026-09-09T12:52:39.886Z).
Wrote 14 files under .speclayer/.
Wrote component-specs/ (1 file).
Wrote tokens/ (8 files, web/css, kebab names).
exit=0                                 (dark file back again)

$ node .../cli.js skill --install
Updated AGENTS.md (agents-md, detected in this repository).
exit=0
```

`AGENTS.md` now names `component-specs/`, `tokens/index.css`, and all
eight files including `semantic-colors.dark.css`, and no longer mentions
`.speclayer/components/`.
